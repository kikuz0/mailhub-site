プライバシーポリシー

本ポリシーは、KSS合同会社（以下「運営者」）が提供するメール整理ツール「mailhub」（以下「本ツール」）における利用者情報の取り扱いを定めるものです。

1. 取得する情報

本ツールは、利用者の許可を得たうえで、Google API を通じて利用者の Gmail アカウントから次の情報を読み取ります。

  • メールの識別子、スレッド識別子、Message-ID
  • 送信日時、差出人、宛先、件名
  • ラベル、既読・未読の状態、サイズ、本文冒頭の短い抜粋（Gmail が提供するスニペット）

要求するアクセス権は読み取り専用（https://www.googleapis.com/auth/gmail.readonly）のみです。メールの送信、削除、変更は行いません。

2. 利用目的

取得した情報は、利用者自身がメールを一覧・検索・整理し、対応が必要なメールを把握する目的にのみ使用します。

3. 保存場所と第三者提供

  • 取得した情報および認証トークンは、利用者のPC内のファイルにのみ保存します。運営者を含む外部のサーバーへは送信しません。
  • 取得した情報を第三者に販売・提供・共有することはありません。
  • 広告の配信、広告のための分析、信用調査などには使用しません。

4. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から取得した情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

5. 情報の削除とアクセスの取り消し

利用者は、PC内に保存されたファイルを削除することで、取得した情報をいつでも消去できます。また、Google アカウントのアクセス管理から本ツールへのアクセスをいつでも取り消せます。

6. 利用者の範囲

本ツールは一般に提供しておらず、運営者本人が保有するアカウントでのみ使用します。

7. 改定

本ポリシーを改定する場合は、このページで公表します。
